# СТО «Правда» — сайт автосервиса

Статический сайт на [Astro](https://astro.build): чистый CSS с переменными, минимум vanilla JS.
Главная идея — «Открытый заказ-наряд»: цены, этапы, старые детали, гарантия.

## Запуск

Нужен Node.js 20+ (проверено на 22).

```bash
npm install
npm run dev        # локально: http://localhost:4321
npm run build      # сборка в dist/
npm run preview    # просмотр собранного dist/
```

Папку `dist/` можно залить на любой хостинг (статические файлы).

### Адрес сайта и подпуть

Адрес задаётся переменными окружения при сборке:

| Где | `SITE_URL` | `BASE_PATH` |
|---|---|---|
| Свой домен (по умолчанию) | `https://sto-pravda.by` | `/` |
| GitHub Pages | `https://dirol982.github.io` | `/pravda` |

```bash
SITE_URL=https://dirol982.github.io BASE_PATH=/pravda npm run build
```

От них зависят canonical, sitemap, robots.txt, OG-теги и все внутренние ссылки.

### Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает сайт при пуше в `main` (или вручную, Actions → Run workflow)
и публикует его на `https://dirol982.github.io/pravda/`.
В настройках репозитория: **Settings → Pages → Source: GitHub Actions**.
Для своего домена поменяйте в workflow `SITE_URL`/`BASE_PATH` и добавьте `public/CNAME`.

## Где что править

Все данные — в `src/data/*.json`. Страницы генерируются из них, в вёрстке цены не прописаны.

| Файл | Что внутри |
|---|---|
| `contacts.json` | адрес, координаты, телефоны, мессенджеры, соцсети, юрлицо, способы оплаты, **часы работы** |
| `services.json` | направления услуг, тексты страниц, симптомы, связанные услуги, **прайс** |
| `vibrostend.json` | цены вибростенда, что проверяем, выгоды, пример экономии, FAQ |
| `promos.json` | акции |
| `reviews.json` | 3 отзыва для главной |
| `quiz.json` | варианты ответов квиза и ссылки на позиции прайса |
| `site.json` | меню, ID Яндекс.Метрики, сноска к ценам |

Поля, которые начинаются с `_` (`_todo`, `_note`), служебные и на сайт не выводятся.

### Цены

Позиция прайса в `services.json`:

```json
{ "id": "05.03", "name": "Замена дисковых колодок", "price": 50, "from": false,
  "priceJeep": 50, "jeepFrom": false, "unit": "ось", "verified": false }
```

- `price` — число в рублях; `null` = «по запросу»; `0` = «бесплатно».
- `from: true` — выводится «от 50 р.».
- `priceJeep` — цена для джипа/микроавтобуса (если есть, на странице появляется вторая колонка, а в `/ceny/` работает переключатель).
- `verified` — поставьте `true`, когда владелец сверил цену.
- `id` (`05.03`) — номер позиции в заказ-наряде. На него ссылается квиз (`quiz.json` → `priceRef`), поэтому id не меняйте.

Новое направление = новый объект в `categories`; страница `/uslugi/<slug>/`, плитка, прайс и sitemap появятся сами.

### Часы работы

`contacts.json` → `hours.week`: для каждого дня `["09:00", "20:00"]` или `null` (выходной).
Из этих данных строятся статус «Открыто до… / Закрыто, откроемся…» (по времени Europe/Minsk),
часы в футере и на странице контактов, `openingHours` в Schema.org.

### Фото

Плейсхолдеры лежат в `public/photos/` (`boks`, `master`, `klientskaya-zona`, `vibrostend`, `vhod`) в двух форматах: `.webp` и `.avif`.
Замените файлы реальными фото с теми же именами (WebP и AVIF; например `npx @squoosh/cli` или любой конвертер).
Подпись «Фото: …» задаётся в компоненте `<Photo label=…>`.
Пересоздать плейсхолдеры, favicon и OG-картинку: `npm run placeholders` (перезапишет файлы!).

### Цвет акцента

`src/styles/global.css` → `--accent`. Там же остальные токены (фон, текст, линии, шрифты) и тёмная тема (`prefers-color-scheme`).

## Устройство

```
src/
  data/          JSON — единственный источник данных
  lib/site.ts    форматирование цен, ссылки с учётом BASE_PATH, часы работы
  layouts/Base.astro   <head>, SEO, Schema.org AutoRepair + BreadcrumbList, статус «Открыто», появление блоков
  components/    Header, Footer, MobileBar, PriceTable, Quiz, Cta, Photo, Icon…
  pages/         /, /uslugi/, /uslugi/[slug]/, /ceny/, /vibrostend/, /akcii/, /yurlicam/, /kontakty/, /cookie/, 404, robots.txt
public/          favicon, og.png, photos/
scripts/gen-placeholders.mjs
```

- Шрифты Google Fonts (Unbounded, Manrope, JetBrains Mono) подключены self-host через `@fontsource`:
  только кириллица + латиница, без стороннего блокирующего CSS (это дало +10–15 баллов Lighthouse Performance).
- Квиз собирает текст заявки и открывает Viber (`viber://chat?number=…&draft=…`), Telegram (`t.me/<user>?text=…`)
  или WhatsApp (`wa.me/<номер>?text=…`). Текст одновременно копируется в буфер — на случай, если приложение не подставит черновик.
- Виджет отзывов Яндекса грузится только по клику, карта — `loading="lazy"`.
- Анимации отключаются при `prefers-reduced-motion`.
