# СТО «Правда» — сайт

Статический сайт на чистом HTML/CSS/JS (по шаблону v4, как vagmotors). Сборки нет: файлы лежат в корне, GitHub Pages отдаёт их из ветки `main`.

- Адрес: https://dirol982.github.io/pravda/
- Страницы: `index.html`, `uslugi/<направление>/`, `ceny/`, `vibrostend/`, `akcii/`, `yurlicam/`, `kontakty/`, `cookie/`, `404.html`
- Стили: `assets/css/style.css` (шаблон), `motion.css` (анимации), `palettes.css` (цветовые варианты), `site.css` (доработки «Правды»)
- Скрипты: `assets/js/main.js` (калькулятор, запись, лента), `tw.js` (тема, палитра, статус «Открыто», сезонная плитка), `motion.js` (анимации), `vibro.js` (страница вибростенда)
- Фото: `assets/img/` (WebP, 1440 и 720 px)

## Цветовые варианты

Переключатель в шапке (кружок): Золото (фирменный, из логотипа), Сигнал, Красный, Синий + светлая/тёмная тема. Выбор запоминается.
Прямые ссылки на варианты:

- https://dirol982.github.io/pravda/?palette=gold
- https://dirol982.github.io/pravda/?palette=signal
- https://dirol982.github.io/pravda/?palette=red
- https://dirol982.github.io/pravda/?palette=blue
- светлая тема: добавьте `&theme=light`

Основной вариант по умолчанию — атрибуты `data-palette` и `data-theme` у `<html>` в каждой странице.

## Что где править

- **Телефоны, Telegram, Viber, WhatsApp, часы работы, чипы «Что беспокоит?»** — JSON `<script type="application/json" id="site-cfg">` в `<head>` каждой страницы (одинаковый во всех файлах — меняйте поиском-заменой по проекту).
- **Цены калькулятора** — JSON `<script type="application/json" data-calc-data>` в `index.html`: `[{id:"car"|"jeep", cats:[{name, items:[{name, price, from}]}]}]`. `from:false` — цена без «от».
- **Цены на страницах** — таблицы в `ceny/index.html` и `uslugi/*/index.html`.
- Цены «от», BYN, работы без запчастей; взяты со старого сайта и **не сверены владельцем** — сверить.

## Фото
